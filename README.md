# 库房大屏助手：三种 Agent 架构对照

同一个档案库房值守场景，用三种控制流各实现一遍。差别不在业务，而在**自主权交给模型多少**。

业务口径取自真实的三维库房大屏系统：空间树按「楼宇 → 楼层 → 库房 → 库区 → 密集架」组织，
库区带别名（`v6` 归一到 V6库区，`低氧` 归一到低氧库区）；设备用 UUID 作为 `tbProfileId`；
档案检索的档号条件与类型条件互斥；设备控制只接通断路器合闸分闸与门禁开关门两类真实 RPC。

## 快速开始

```bash
export DASHSCOPE_API_KEY=sk-xxx
pip install -r requirements.txt

python 01-reactive/warehouse_react_agent.py
python 02-hybrid/warehouse_hybrid_agent.py
python 03-deliberative/warehouse_deliberative_agent.py
```

三个脚本都支持在仓库根目录或各自目录下直接运行。模型可用 `LLM_MODEL` 覆盖，
端点可用 `LLM_BASE_URL` 覆盖，默认是百炼的 OpenAI 兼容端点。

## 三种架构对照

| | 01 反应式 | 02 混合式 | 03 深思熟虑 |
|---|---|---|---|
| 控制流决策者 | 模型全程决定 | 路由一次，之后分派 | 代码写死 |
| 模型调用次数 | 不固定，直到自己收尾 | 简单 2-3 次，复杂 2 次 | 固定 5 阶段 |
| 能否中途改路径 | 能 | 不能，路由后固定 | 不能 |
| 谁来调工具 | 模型自己决定 | 简单分支模型决定，复杂分支代码指定 | 代码指定 |
| 典型任务 | 单目标查询 | 混合负载 | 结构固定的产出物 |
| 主要风险 | 循环不收敛 | 路由分错 | 撞上意外情况无法转向 |

一句话概括差异：

- **反应式**把每一步都交给模型，灵活但需要靠轮次上限兜底。
- **混合式**只交出简单查询，复杂请求改由代码编排，兼顾灵活与稳定。
- **深思熟虑**完全不交出控制流，模型只填内容，产出结构最稳定。

## 目录结构

```
warehouse-agent-architectures/
├── warehouse_data.py         三个项目共用的域数据、工具与模型入口
├── requirements.txt
├── 01-reactive/              反应式：模型自主循环
├── 02-hybrid/                混合式：路由 + 两条分支
└── 03-deliberative/          深思熟虑：五阶段流水线
```

`warehouse_data.py` 提供四套域数据（空间树、设备台账、档案台账、能源环境）、六个工具、
职责范围预检与模型客户端。三个项目共用它，避免同一套台账写三遍导致口径漂移。

## 六个工具

| 工具 | 作用 |
|---|---|
| `resolve_scene_target` | 把自然语言位置解析成标准路径，返回密集架清单 |
| `query_device_status` | 查设备台账与实时状态，区分是否可控 |
| `control_device` | 下发控制指令，按响应码回报真实结果 |
| `search_archive` | 按档号或类型检索档案，两个条件互斥 |
| `query_energy_stat` | 查库房能耗，支持全楼汇总 |
| `query_environment` | 查温湿度并按阈值判定告警 |

## 设计上的三条坚持

**数据只有一份。** 三个项目共用 `warehouse_data.py`，改一台设备只改一处。

**复杂分析必须真取数。** 混合式的对比分支和深思熟虑的感知阶段都直接调用工具取数，
再由模型归纳，不允许模型凭空生成数据——否则复杂分析反而建立在幻觉上。

**失败要显式暴露。** 路由分类拿不到明确结果就抛错，不默认降级到某条分支；
工具返回非 0 响应码时如实转述，不改写成成功；工具没返回的信息就回答「系统中未查询到」。

## 已验证的行为

| 场景 | 表现 |
|---|---|
| 低氧区定位 | 别名归一命中，返回标准路径与两组密集架 |
| 断路器分闸 | 真实改写状态，返回 `code 0 已分闸` |
| 模式类动作 | 明确拒绝并说明只支持合闸分闸与开关门 |
| 离线设备控制 | 返回离线错误，指令不下发 |
| 档案检索互斥 | 同时给档号与类型时返回互斥错误 |
| 档案正文解读 | 入口拦截，不进入模型 |
| 跨库房能耗对比 | 混合式走分析分支，数字全部来自真实采集 |
| 季度巡检报告 | 五阶段产出完整报告，数字可逐一追溯 |
